# Internacionalização (`src/i18n/ui.ts`)

Estrutura: `ui = { pt: {...}, en: {...} }`, mesmas chaves nos dois lados.
Valores podem ser string, função (`(n) => …`) ou array; o **tipo** precisa casar entre PT e EN.

Verificação: `node .claude/skills/content-integrity/scripts/check-i18n.mjs`
(lista chaves só de um lado e tipos divergentes; exit 1 se houver).

Blocos relevantes: `nav`, `theme`, `language`, `term` (comandos, `nav`, `firstVisit`, `try`), `cmdbar`,
`timeline`, `lightbox`, formulário de contato. Texto novo de terminal entra em `term.*`.
Trocar o idioma redesenha a saída do terminal: por isso o texto nunca é congelado em `output`.
