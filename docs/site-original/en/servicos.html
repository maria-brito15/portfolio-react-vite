✦ About design

What about the design?

All projects already come with a visual — you don't need to worry about that. If you don't have a design, I create the interface using tools like Figma Make: you send me the idea, references, or style you like, and I put together something suitable for the project. If you already have a design ready in Figma or a well‑defined reference, I replicate it faithfully.

⚠️ I'm not a professional designer — the focus is to deliver something functional and presentable. For projects that require elaborated visual identity or branding, I recommend involving a specialized designer.
